# Mass Hisab Frontend

Next.js App Router + TypeScript + Bootstrap 5 frontend.

## Run locally

From the repository root:

```bash
npm run install:frontend
npm run dev:frontend
```

Open http://localhost:3000.

## Screens

- `/login` and `/register`
- `/dashboard` overview
- `/dashboard/meals`
- `/dashboard/members`
- `/dashboard/bazar`
- `/dashboard/deposits`
- `/dashboard/expenses`
- `/dashboard/reports`
- `/dashboard/manager`
- `/dashboard/settings`

## Integration status

Screens currently use representative demo data and client-side form interactions. Authentication, role permissions, persistence and financial calculations are presentation-only until the API is connected. Do not use demo figures as actual mess accounts.

Bootstrap 5 and Bootstrap Icons are used; Tailwind CSS is not used.
